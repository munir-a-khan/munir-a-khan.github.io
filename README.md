# Munir Khan portfolio

Static professional portfolio, published with GitHub Pages. Plain HTML/CSS and a small clipboard helper; no build dependencies, analytics, backend, or external fonts. The email remains visible and selectable without JavaScript.

Publish from `main` at `/`. Images and project context are documented in [PROVENANCE.md](PROVENANCE.md). Edit `index.html` and `style.css` to update the site. Keep private source, resumes, reports, logs, and credentials out of this repository.
